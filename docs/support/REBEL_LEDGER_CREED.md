# Rebel Ledger Creed

We do not ask permission to make evidence runnable.

We do not treat publication as the first gate of truth.

We build bounded artifacts.

We state the smallest claim.

We state what it does not prove.

We run the verifier.

We preserve the transcript.

We accept the first failure as authoritative.

We repair one structural gap at a time.

We do not confuse attention with adoption.

We do not confuse praise with validation.

We do not confuse rejection with refutation.

We track only what can be run, reused, forked, cited, or extended.

A paper may explain. A review may improve. A journal may archive.

The ledger records what executes.

Our unit of progress is not approval.

Our unit of progress is a bounded object that survives contact with another machine, another reader, or another builder.

We do not claim the whole theory when one artifact runs.

We do not hide the boundary.

We make it visible enough that criticism must engage the object, not the myth around it.

This is not anti-publication. This is publication after execution.

This is not anti-review. This is review with a runnable target.

This is not anti-institution. This is evidence that can stand before institution.

The Rebel Ledger begins where permission ends:

a clean clone, a stated boundary, a verifier output, a passing test, and a record others can reproduce.

We build so the next outsider has a scaffold.

We record so the next rejection is not silence.

We run so the next claim is not merely belief.

We do not wait for legitimacy to begin.

We make legitimacy inspectable.
